# User Preferences & Execution Rules

1. **Command Efficiency**: Minimize PowerShell/terminal commands. Avoid unnecessary polling, looping, or redundant background tasks.
2. **Concise Output**: In final results, provide ONLY a clear summary of actual changes without fluff or conversational filler.
3. **Relevant Options**: When offering suggestions or recommendations, present 2-3 of the most relevant options.
4. **Analyze Before Executing**: When the user provides a suggestion or instruction:
   - Do NOT execute immediately.
   - First investigate, analyze feasibility, and evaluate whether the suggestion is worth implementing or has potential drawbacks.
   - Present the analysis clearly before proceeding.
